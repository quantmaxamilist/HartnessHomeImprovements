HARTNESS HOME IMPROVEMENTS — website
=====================================
Static HTML/CSS/JS built off the same template as Scarlatt. No build step.
Open in Cursor; preview index.html with Live Server, or deploy the folder to
Vercel (preset: Other) or any host via FileZilla/cPanel.

Pages: index · services · about · contact · book (appointment booking)
Theme: professional navy #1c3d5a + brass #bd8a3c on a clean light base.
Fonts: Archivo + Inter. Animations: scroll-reveal, hero ken-burns, hover lifts.
Real content: team photos, Constructionline Gold badge, real client testimonials,
owner "Lewis", Strathaven / South Lanarkshire service area.
